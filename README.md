Entry for the make.fun bounty "The Funniest Excuse for Skipping a Meeting" (slug `u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163`).
See the bounty: https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163

`main.py` (Python 3 standard library only) writes a single funny excuse, at most 200 characters, to `output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The excuse

**Sorry, I can't attend — I'm double-booked with a meeting about why this meeting should have been an email.**

It is funny because it turns the meeting against itself: the only thing more important than this pointless meeting is a meeting about how pointless it is. Short, true to office life, and no wifi, cat, or dentist in sight.
